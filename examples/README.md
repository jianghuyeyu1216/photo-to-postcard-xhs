# Examples

This folder contains official example outputs generated with the default Photo to Zine Postcard skill.

The initial example set covers several visual categories so users can understand how motif selection adapts to different photographs:

- `forest-homestead` — forest, cabin, horse
- `alpine-glow` — snow mountain and warm alpenglow
- `turquoise-lake` — lake, mountain, architecture
- `green-door` — architecture and garden
- `blue-arc-lake` — lake, rainbow, forest
- `turquoise-basin` — aerial water and mineral shoreline
- `lake-at-dusk` — tree, water, cloud
- `college-garden` — historical architecture and garden
- `valley-current` — alpine valley, river, forest

Each example demonstrates the same core structure:

1. original photo above
2. large transition whitespace
3. minimal metadata on the lower left
4. one hand-drawn source-specific scene or motif on the lower right
5. three source-derived color swatches

Example images are visual references, not additional rules. `SKILL.md` remains the single source of truth for generation behavior.
